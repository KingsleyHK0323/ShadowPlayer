Overview

Current status

ShadowPlayer is an early-stage project. The application is not runnable yet, and its technical architecture is still being developed.

Machine learning for gameplay, optional local and cloud AI model connections, and using these approaches together are project goals. They have not been demonstrated as working features.

Getting started

Installation and first steps

There is no application to install yet. Installation instructions and a quick-start guide will be documented when a runnable build is available.

For now, visit the GitHub repository to follow project updates.

Configuration

Local and cloud models

The project aims to support local and cloud AI models, including use alongside machine learning. Integration, provider support, credentials, and configuration are not implemented or verified.

There are no model setup instructions or API settings to configure yet.

Compatibility

Platforms and games

Windows is the initial target. The project aims not to restrict players to particular games, but no operating system or game compatibility has been verified.

A compatibility guide can be added when there is a build and evidence from testing.
